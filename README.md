# Đồ Án: Sàn Nông Nghiệp Sạch & Truy Xuất Nguồn Gốc (AgriTrace)

Hệ thống Sàn thương mại điện tử nông sản kết hợp Dữ liệu cảm biến IoT và Mã QR Truy xuất nguồn gốc.

## 🛠 Công nghệ sử dụng
- **Backend:** Python, Django REST Framework, PostgreSQL
- **Frontend:** React, TailwindCSS

## 🚀 Hướng dẫn Chạy Backend
1. Di chuyển vào thư mục backend: `cd backend`
2. Kích hoạt venv: `.\venv\Scripts\activate`
3. Chạy Server: `python manage.py runserver`
